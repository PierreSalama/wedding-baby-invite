# Wedding + Baby Shower Invite

This folder is now intentionally documentation-only.

The first implementation was removed because it missed the bar on visual quality, readability, desktop presentation, and the envelope-opening experience. The next build should start from research-backed references and a stronger design system, not from the discarded code.

## What this folder is for

Use this folder as the planning package for a fresh rebuild of a combined wedding and baby shower invitation website.

Primary goals:

- mobile-first, especially iPhone Safari
- real desktop presentation, not a stretched mobile mockup
- elegant green-and-white visual direction
- high-quality envelope opening interaction based on proven reference work
- simple RSVP capture for about 50 total guests
- free or near-free deployment and storage

## What was removed

All previous app code, build tooling, frontend files, backend files, and deployment config were removed on purpose. Only the documentation remains.
