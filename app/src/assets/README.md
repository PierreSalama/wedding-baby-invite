# Dropping in real venue photos

The Location page automatically picks up venue photos if you drop them here.

## Church photo (St. Clement's Parish)

Save a JPG/PNG/WebP of the church here as one of:

```
src/assets/church.jpg
src/assets/church.png
src/assets/church.webp
src/assets/church.jpeg
```

The illustrated church icon will be replaced automatically — no code changes needed. Vite HMR will reload.

Recommended dimensions: at least 800×600px. Will be displayed as a 16:9-ish banner above the venue details (cropped via `object-cover`).

## Gender reveal photo
